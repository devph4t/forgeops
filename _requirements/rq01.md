# ForgeOps Cluster Requirements & Pod Status

## 1. Objective

Build a Kubernetes cluster based on:

* Base repository: `https://github.com/ForgeRock/forgeops`
* Base branch: `main`

The target environment must deploy and run the required ForgeRock / Ping Identity components as Kubernetes workloads.

Primary focus of this document:

* Required Pods
* Pod status
* Replica count
* Pod dependencies
* Deployment progress
* Health validation

## 2. Target Cluster Required Components

The cluster should contain the following components:

1. ForgeRock Directory Server
2. PingAM
3. PingIDM
4. Ping Platform UI
5. ForgeRock Directory Server - Token Store
6. ForgeRock Directory Server - User Store
